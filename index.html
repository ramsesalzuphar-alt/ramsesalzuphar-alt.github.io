Clipbot

Clipbot is a private desktop tool that turns livestreams into short vertical clips with captions and uploads them to fan clip channels on YouTube. Its owner runs it on their own computer, and only for channels they own. It is not offered to the public and has no sign-up.

Clipbot uses YouTube API Services. Each clip's description links back to the original creator, and every channel is labeled as a fan or clip channel.
